# 🎵 Хвиля (Khvylia) — Музичний веб-сервіс

> **Дипломна робота**  
> Студента Запорізького національного університету (ЗНУ)  
> Сучасний веб-сервіс для персоналізованого прослуховування музики, організації треків та взаємодії зі Spotify API.

---

## 📖 Про проєкт

**«Хвиля»** — це повнофункціональний музичний стрімінговий веб-додаток, створений для швидкого пошуку, прослуховування та організації музичних треків. Сервіс поєднує можливості стрімінгу через **Spotify Web API & Web Playback SDK**, власну базу даних для зберігання користувацьких плейлистів, тегів, улюблених треків і соціальних підписок, а також модуль синхронізованих текстів пісень (караоке).

---

## ✨ Основні можливості

- **🎧 Безперервне відтворення (Persistent Global Player)**: Завдяки технології View Transitions (`astro-vtbot`) відтворення музики не переривається під час переходу між будь-якими сторінками додатку.
- **🎤 Караоке та синхронізовані тексти**: Автоматичний пошук і відображення слів пісні у реальному часі синхронно з музикою (LRC-формат).
- **🎶 Керування чергою відтворення**: Динамічна черга, збереження контексту (звідки запущено трек: плейлист чи рекомендації), режими перемішування (**Shuffle**) та повтору (**Repeat**).
- **📁 Плейлисти та персональна медіатека**:
  - Створення власних публічних або приватних плейлистів.
  - Додавання треків у плейлисти безпосередньо з пошуку або рекомендацій.
  - Збереження вподобаних плейлистів інших користувачів.
- **🏷️ Система персональних тегів**: Можливість додавати власні кольорові теги до треків у плейлистах для зручної швидкої фільтрації.
- **❤️ Улюблені треки (Favorites)**: Швидке додавання треків до обраного в один клік з будь-якого місця системи.
- **📜 Історія прослуховувань**: Автоматична фіксація нещодавно прослуханих пісень.
- **👤 Профілі та соціальна взаємодія**:
  - Персональний кабінет користувача з можливістю завантаження аватара.
  - Підписки на інших користувачів (**Followers / Following**).
  - Перегляд публічних профілів, їхніх плейлистів та активності.
- **🔐 Безпека та сесії**:
  - Авторизація за допомогою JWT (JSON Web Tokens) та хешування паролів (`bcrypt`).
  - Відстеження активних сесій та пристроїв користувача з можливістю віддаленого завершення сесій.
- **🌗 Адаптивний дизайн та теми**:
  - Повноцінна темна (фіолетово-неонова) та світла теми з синхронізацією у налаштуваннях профілю.
  - Адаптивний мобільний інтерфейс з повноекранним мобільним плеєром.
- **🌍 Мультимовність (i18n)**: Повна підтримка української (`uk`) та англійської (`en`) мов з миттєвим перемиканням.

## 🛠️ Технологічний стек

### Клієнтська частина (Frontend)
- **Фреймворк**: [Astro 5+](https://astro.build/) (режим SSR через `@astrojs/node`)
- **UI-компоненти**: [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- **Стилізація**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Плавна навігація**: `astro-vtbot` (Astro View Transitions persistence)
- **Інтернаціоналізація**: `vue-i18n` + кастомні Astro-хелпери
- **Типізація**: TypeScript

### Серверна частина (Backend)
- **Платформа**: [Node.js](https://nodejs.org/) (версія >= 22.12.0)
- **Серверний фреймворк**: [Express 5](https://expressjs.com/) (TypeScript)
- **ORM**: [Prisma ORM 7+](https://www.prisma.io/)
- **База даних**: PostgreSQL (підтримка Supabase Connection Pooling)
- **Безпека**: `jsonwebtoken` (JWT), `bcrypt`
- **Завантаження файлів**: `multer` (обробка аватарів)
- **Spotify Інтеграція**: Spotify Web API & Spotify Accounts OAuth

### Модуль текстів пісень (караоке)
- **Мова**: Python 3
- **Бібліотека**: `syncedlyrics` (автоматичний пошук синхронізованих LRC через NetEase, Lrclib, Megalobiz)

## 🚀 Встановлення та запуск

### 1. Системні вимоги
- **Node.js**: версія `22.12.0` або новіша
- **npm**: версія `10+`
- **Python**: версія `3.9+` (з пакетним менеджером `pip`)
- **PostgreSQL**: локальна БД або хмарний інстанс (наприклад, [Supabase](https://supabase.com/))
- **Spotify Developer App**: зареєстрований додаток на [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)

---

### 2. Клонування репозиторію
```bash
git clone <URL_РЕПОЗИТОРІЮ>
cd diploma_music_service
```

---

### 3. Налаштування серверної частини (`server`)

1. Перейдіть до папки сервера та встановіть залежності:
   ```bash
   cd server
   npm install
   ```

2. Встановіть Python-залежність для караоке:
   ```bash
   pip install syncedlyrics
   ```

3. Створіть файл змінних оточення `.env` у папці `server/` на основі `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Заповніть відповідні параметри:
   ```env
   # Рядок підключення до PostgreSQL (наприклад Supabase)
   DATABASE_URL="postgresql://user:password@host:5432/dbname?schema=public"
   DIRECT_URL="postgresql://user:password@host:5432/dbname?schema=public"

   PORT=5001
   JWT_SECRET="ваш_надійний_секретний_ключ"

   # Отримані в Spotify Developer Dashboard
   SPOTIFY_CLIENT_ID="ваш_spotify_client_id"
   SPOTIFY_CLIENT_SECRET="ваш_spotify_client_secret"
   ```

4. Застосуйте міграції Prisma для ініціалізації таблиць у базі даних:
   ```bash
   npx prisma generate
   npx prisma migrate deploy
   ```

5. Запустіть сервер у режимі розробки:
   ```bash
   npm run dev
   ```
   *Сервер працюватиме на `http://localhost:5001`.*

---

### 4. Налаштування клієнтської частини (`client`)

1. Відкрийте новий термінал, перейдіть до папки `client/` та встановіть залежності:
   ```bash
   cd client
   npm install
   ```

2. Запустіть клієнтський dev-сервер:
   ```bash
   npm run dev
   ```
   *Клієнт буде доступний за адресою `http://localhost:4321`.*

3. Для перевірки або створення продакшн-збірки:
   ```bash
   npm run build
   ```

## 🎯 Як користуватися сервісом

1. **Реєстрація та вхід**: Перейдіть на `http://localhost:4321`, створіть обліковий запис або увійдіть під існуючим.
2. **Підключення Spotify**: У плеєрі або в налаштуваннях профілю підключіть ваш обліковий запис Spotify для доступу до повноцінного відтворення треків.
3. **Пошук музики**: Використовуйте поле пошуку у верхній шапці для пошуку улюблених виконавців, треків та альбомів.
4. **Створення плейлистів**: Перейдіть до свого профілю, створіть плейлист і додавайте до нього треки, присвоюйте кольорові теги для фільтрації.
5. **Караоке**: Під час відтворення треку натисніть кнопку з мікрофоном у плеєрі для відкриття синхронізованих слів пісні.
6. **Зміна теми та мови**: У правому верхньому куті доступне перемикання тем (світла/темна) та мов інтерфейсу (UA/EN).
