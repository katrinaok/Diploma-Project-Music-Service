> Стек: **Astro 5 + Vue 3 + Tailwind CSS v4 | Express 5 + TypeScript + Prisma 7 + PostgreSQL**

---

## 📖 Про проєкт

**«Хвиля» (Khvylia)** — сучасний повнофункціональний музичний стрімінговий веб-додаток, створений для швидкого пошуку, прослуховування та організації музичних композицій.

Сервіс побудовано за клієнт-серверною архітектурою. Він об'єднує можливості глобального музичного каталогу та стрімінгу через **Spotify Web API & Web Playback SDK**, власну реляційну базу даних **PostgreSQL** для зберігання авторських плейлистів, кольорових тегів, улюблених треків, активних сесій та соціальних підписок, а також інтегрований рушій синхронізованих текстів пісень (караоке).

---

## ✨ Основні можливості та переваги

### 🎧 1. Безперервне відтворення (Persistent Global Player)
- Завдяки архітектурі **View Transitions** (`astro-vtbot`), аудіоплеєр продовжує безперервно відтворювати трек при переходах між сторінками веб-додатку без затримок чи перезавантаження сторінки.
- Повна інтеграція зі **Spotify Web Playback SDK**: можливість транслювати музику у високій якості, синхронізація статусу між пристроями через екосистему Spotify Connect.
- Динамічна черга відтворення (Queue), збереження контексту джерела треку, підтримка режимів перемішування (**Shuffle**) та циклічного повтору (**Repeat**).
- Адаптивний повноекранний мобільний плеєр з підтримкою свайпів.

### 🎤 2. Синхронізовані караоке-тексти пісень (Synced Lyrics)
- Автоматичний пошук та парсинг часових міток слів пісні у форматі LRC у реальному часі.
- Плавне масштабування та градієнт фокусу на поточному рядку з апаратною GPU-акселерацією (без ривків і стрибків макета).
- Автоматичне скролювання до активного рядка з можливістю плавного ручного перегляду колесиком миші чи тачем та швидкою кнопкою «До поточної стрічки».

### 📁 3. Повноцінне керування плейлістами
- **Створення та налаштування**: публічні або приватні плейлісти з можливістю редагування назви, опису та обкладинки.
- **Динамічний 4-елементний колаж обкладинок**: автоматичне формування естетичного сіткового колажу з обкладинок перших 4 треків або ручне завантаження власного зображення.
- **Організація треків**: зміна порядку треків, сортування та швидке видалення.
- **Збереження плейлістів**: збереження вподобаних публічних плейлістів інших користувачів у свою бібліотеку.
- **Конфіденційність та захист**: при переведенні плейліста в статус «Приватний» чужі збереження автоматично очищаються, а переглядати список людей, які зберегли плейліст, може виключно його творець.

### 🏷️ 4. Персональна система тегів
- Додавання кольорових міток-тегів до треків усередині плейліста.
- Зручна та миттєва фільтрація треків за настроєм, жанром або подією без потреби розбивати плейліст на окремі підзбірки.

### 🔍 5. Розумний гібридний пошук (Smart Hybrid Search)
- Поєднання офіційного каталогу Spotify API з алгоритмом нечіткого пошуку (Fuzzy Search за відстанню Левенштейна та фонетичними евристиками).
- Підказка результатів, історія нещодавніх пошукових запитів, пошук треків, артистів та альбомів.

### 👤 6. Соціальна складова та профілі користувачів
- Персональний кабінет користувача з завантаженням аватара через `multer`.
- Взаємні підписки (**Followers / Following**) з можливістю перегляду списків підписників.
- Публічні сторінки профілів інших користувачів із переліком їхніх відкритих плейлістів.
- Можливість приховати свій профіль від сторонніх користувачів (приватний акаунт).

### 🔐 7. Безпека, сесії та пристрої
- Надійна аутентифікація через **JWT (JSON Web Tokens)** з терміном дії та захистом ендпоінтів.
- Хешування паролів за стандартом **bcrypt**.
- Менеджер активних сесій: відстеження пристроїв, операційних систем і браузерів користувача з можливістю дистанційного завершення сесій.

### 🎨 8. Дизайн, адаптивність та мультимовність
- Підтримка контрастної темної (фіолетово-неонової) та світлої тем з автоматичним збереженням уподобань.
- Повна підтримка української (`uk`) та англійської (`en`) мов із правильною граматичною плюралізацією («1 трек», «2 треки», «5 треків»).

## 🛠️ Технологічний стек

### Клієнтська частина (Frontend)
- **Фреймворк**: [Astro 5+](https://astro.build/) (гібридний режим рендерингу SSR через `@astrojs/node`)
- **UI-бібліотека**: [Vue 3](https://vuejs.org/) (Composition API, `<script setup>`)
- **Стилізація**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Плавна навігація**: `astro-vtbot` (Astro View Transitions persistence для аудіоплеєра)
- **Інтернаціоналізація**: `vue-i18n` + власні типізовані утиліти локалізації
- **Мова**: TypeScript

### Серверна частина (Backend)
- **Платформа**: [Node.js](https://nodejs.org/) (v22+)
- **Веб-сервер**: [Express 5](https://expressjs.com/) (TypeScript)
- **ORM**: [Prisma ORM 7+](https://www.prisma.io/)
- **Драйвер бази даних**: PostgreSQL + пул підключень через `@prisma/adapter-pg`
- **Безпека**: `jsonwebtoken`, `bcrypt`
- **Завантаження файлів**: `multer`
- **Змінні середовища**: `@dotenvx/dotenvx` / `dotenv`
- **Інтеграція Spotify**: Spotify Web API, Spotify Accounts OAuth 2.0 PKCE / Authorization Code Flow

### Модуль текстів пісень (Караоке)
- **Мова**: Python 3
- **Бібліотека**: `syncedlyrics` (інтеграція з базами NetEase, Lrclib, Megalobiz)

## 🚀 Встановлення та запуск

### 1. Системні вимоги
- **Node.js**: версія `22.12.0` або новіша
- **npm**: версія `10+`
- **Python**: версія `3.9+` (з пакетним менеджером `pip`)
- **PostgreSQL**: локальна БД або хмарний сервіс (наприклад, [Supabase](https://supabase.com/))
- **Spotify Developer App**: зареєстрований додаток на [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) (для отримання Client ID та Client Secret)

---

### 2. Клонування репозиторію
```bash
git clone <URL_РЕПОЗИТОРІЮ>
cd diploma_music_service
```

---

### 3. Налаштування серверної частини (`server`)

1. Перейдіть у папку сервера та встановіть npm-залежності:
   ```bash
   cd server
   npm install
   ```

2. Встановіть Python-модуль для пошуку текстів пісень:
   ```bash
   pip install syncedlyrics
   ```

3. Створіть файл `.env` у папці `server/` на основі шаблону `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Вкажіть актуальні значення:
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/khvylia_db?schema=public"
   DIRECT_URL="postgresql://user:password@localhost:5432/khvylia_db?schema=public"

   PORT=5001
   JWT_SECRET="your_strong_secret_jwt_key"

   SPOTIFY_CLIENT_ID="ваш_spotify_client_id"
   SPOTIFY_CLIENT_SECRET="ваш_spotify_client_secret"
   ```

4. Застосуйте міграції Prisma для створення структури таблиць у базі даних:
   ```bash
   npx prisma generate
   npx prisma migrate deploy
   ```

5. Запустіть бекенд-сервер у режимі розробки:
   ```bash
   npm run dev
   ```
   *Сервер працює за адресою: `http://localhost:5001`.*

### 4. Налаштування клієнтської частини (`client`)

1. Відкрийте другий термінал, перейдіть до папки `client/` та встановіть залежності:
   ```bash
   cd client
   npm install
   ```

2. Запустіть клієнтський dev-сервер:
   ```bash
   npm run dev
   ```
   *Клієнтський додаток буде доступний за адресою: `http://localhost:4321`.*

3. Для перевірки працездатності продакшн-збірки:
   ```bash
   npm run build
   ```

## 🎯 Як користуватися застосунком

1. **Авторизація**: Перейдіть на `http://localhost:4321`, створіть обліковий запис або увійдіть під існуючим.
2. **Підключення Spotify**: У плеєрі чи налаштуваннях профілю підключіть Spotify-акаунт (для повноцінного аудіопотоку необхідний Spotify Premium, для прев'ю — будь-який).
3. **Пошук музики**: Знайдіть улюблений трек чи альбом за допомогою інтелектуального пошуку у шапці.
4. **Створення плейлістів**: Створюйте власні тематичні збірки, редагуйте назву, завантажуйте обкладинки чи насолоджуйтесь автоматичним 4-обкладинковим колажем.
5. **Тегування**: Маркуйте треки всередині плейлістів персональними тегами для фільтрації в один клік.
6. **Режим караоке**: Натисніть кнопку з мікрофоном у правому кутку плеєра під час відтворення пісні, щоб співати разом з улюбленими виконавцями.
7. **Кастомізація**: Налаштуйте тему (темна/світла) та мову додатку (UA/EN) у верхньому правому кутку.
